Recepciones
▸ Cómo nombrar una recepción
El código es el nombre corto Conviene cliente + fecha: VW-29-06-2026, GAC-01-06-2026. Sin espacios ni acentos, y no se puede repetir: si el cliente manda dos embarques el mismo día, añade algo que los distinga (VW-29-06-2026-B) o cárgalos como dos listas de la misma recepción con + Lista.

La descripción es texto libre para quien la lea después: los embarques que incluye, o cualquier cosa que convenga recordar. No se usa para buscar.

Nueva recepción

Crea la recepción y sube el packing list. A partir de ahí los operarios pueden empezar a validar desde sus dispositivos.

Catálogo de Depot

Descarga el stock de los clientes configurados y lo guarda localmente. Con esto cada escaneo pasa a ser la lectura de un documento en vez de una llamada al WMS. Hazlo una vez al día, o cuando entren productos nuevos.

Importar códigos de barras · opcional

Excel con SKU y CODIGO DE BARRAS. Se asocian a productos existentes; no crea productos ni cambia conteos. Usa texto para conservar ceros iniciales.
