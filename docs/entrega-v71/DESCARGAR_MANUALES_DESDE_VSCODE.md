# Instrucciones actualizadas de manuales IV ITSANET

La entrega anterior de 40 pasos se sustituyó por el **manual de 38 pasos**, sin los apartados 39 y 40.

Utiliza [la guía actual de captura, generación HTML/PDF, publicación y actualización v72](../entrega-v72/README.md).

Esa guía incluye cómo reemplazar las imágenes del selector de correos, publicar el manual de usuario con acceso autenticado y conservar el técnico en la carpeta del sistema. Los comandos anteriores de esta página apuntaban a una versión que volvía a crear los pasos eliminados; no deben usarse para regenerar los manuales finales.
