El manual tiene 40 pasos: acceso común (01–03), operario (04–18), supervisor
(19–37) y solución de incidencias (38–40). Cada paso muestra dónde trabajar,
qué hacer, qué comprobar, una captura o espacio visual y una precaución concreta.

Se incorporaron capturas de pruebas en 11 pasos. Los otros 29 tienen un espacio
identificado con la pantalla exacta a capturar. No se inventan pantallas ni se
presentan las capturas antiguas como imágenes de producción del 30/10.

## Completar o reemplazar una imagen

1. Descargar el ZIP y descomprimirlo.
2. Abrir `Manual-usuario-completo-IV-ITSANET.html` con Chrome o Edge.
3. Ir al paso y pulsar **Agregar o reemplazar captura**.
4. Seleccionar una imagen PNG/JPG/WebP de hasta 8 MB, sin credenciales ni datos
   personales o de otros clientes que no sean necesarios.
5. Pulsar **Descargar HTML con mis capturas** para conservar la versión completada.
6. Abrir ese HTML descargado y utilizar **Imprimir / PDF**, con papel A4.

La edición es local: las imágenes quedan integradas en el HTML descargado y no
se suben al aplicativo ni al repositorio. No se guardan automáticamente al cerrar
la pestaña. El PDF incluido conserva los espacios pendientes para completar.

El buscador filtra pasos; imprimir o descargar conserva la guía completa. Los
controles de edición no aparecen en el PDF. La lista CSV facilita organizar las
capturas que faltan.
